# Contributing to WingFoil

WingFoil manages its own development with WingFoil: contributions arrive as **Memory elements**
(bug, decision-log, ADR, tech-spec) rather than code pull requests, and are credited to you when an
agent turns them into delivered work.

Start with an [issue](https://github.com/wingfoil/wingfoil/issues) or a
[discussion](https://github.com/wingfoil/wingfoil/discussions); the full model is in
[COLLABORATION.md](https://github.com/wingfoil/wingfoil/blob/main/COLLABORATION.md).
